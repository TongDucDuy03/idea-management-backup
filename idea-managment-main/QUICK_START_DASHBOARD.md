## 🎯 Cách sử dụng ngay:

### 1. Khởi động ứng dụng
```bash
npm start
```

### 2. Truy cập Dashboard
1. Mở trình duyệt tại `http://localhost:3000`
2. Đăng nhập với tài khoản admin
3. Trong trang Admin Dashboard, nhấn nút **"Dashboard Thống kê"**

### 3. Khám phá các tính năng
- **Thống kê cơ bản**: Xem tổng quan số liệu
- **Biểu đồ trực quan**: Phân tích dữ liệu qua biểu đồ
- **Bộ lọc**: Lọc theo thời gian và phòng ban
- **Thống kê nâng cao**: Nhấn "Hiện Thống kê Nâng cao"
- **Xuất PDF**: Nhấn "Xuất Báo cáo PDF"

## 📊 Các loại biểu đồ có sẵn:

1. **Biểu đồ tròn (Doughnut)**: Phân bố trạng thái ý tưởng
2. **Biểu đồ cột (Bar)**: Top phòng ban có nhiều ý tưởng
3. **Biểu đồ đường (Line)**: Xu hướng ý tưởng theo tháng
4. **Biểu đồ tròn (Pie)**: Phân bố trạng thái (nâng cao)
